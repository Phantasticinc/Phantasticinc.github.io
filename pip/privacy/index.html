Pip privacy policy

Pip: Autism Talk (AAC) · Publisher: Phantastic.Vanguard LLC
Effective date: November 12, 2026. This policy describes the Play version of Pip (0.1.27 and later, until a newer date is posted here).

Pip is a communication app for children. It is built so that talking, photos, and settings stay on your device. This policy describes what the app does with information.

What Pip does not do

  • Pip does not ask you to create an account.
  • Pip has no ads, no analytics, and no tracking SDK.
  • The talk board works fully offline and does not need the internet.
  • Pip does not upload your child’s photos, voice, or words to a Pip server. There is no Pip server for this data.

What stays on the device

The following stay on the phone or tablet unless you delete them, clear the app’s data, or uninstall Pip:

  • Personal word photos and labels you add.
  • Settings (voice, celebrations, Lock to Pip, Break Time, and similar choices).
  • The current sentence strip and simple on-device usage counts (for example, words tapped).
  • Short sound recordings, only if a parent uses “Teach Pip my child’s sounds” or “Teach Pip what to ignore” in the optional Calm-down helper. Child-sound samples and ignore samples (for example a TV show, a song, or a laugh track) and the numbers that describe them stay on this device. They are never uploaded. A parent can play, replace, or delete them in Parent settings.

Android backup for Pip is turned off, so Google backup should not copy this information to the cloud.

Backup & Restore

A parent can make a Backup & Restore file of this device’s Pip setup from Parent settings (behind the Grown-ups only questions). The file can include replaced buttons and words, custom pictures and photos, spoken text, favorites and pin order, folder customizations, sentence-length and reward settings, the Break Time approved video list and countdown length, other settings toggles, and — if the parent leaves the default option on — taught child-sound and ignore recordings.

The file is created on the device and saved where the parent chooses, for example to Google Drive, an email to themselves, or a USB drive, using the device’s own share sheet or file picker. Pip does not upload the backup file, does not transmit it to a Pip server, and does not use a cloud account. There is no Pip server for this data. Once the parent saves or shares the file, where it is stored is under the parent’s control. Anyone who has the file can see the setup and any recordings or photos that were included. Pip does not keep a copy of the file after it is saved.

Camera

The camera is optional. It is used only when a parent takes a photo for a personal word. The photo is resized and saved on the device. Pip does not use the camera in the background.

Microphone

Microphone features are optional and off until a parent turns one on. The app will ask for permission first. Audio is processed on the device only.

  • Talk reward: if a parent turns on “Reward when my child tries to talk,” Pip measures sound level on the device to notice a vocalization. That listening is not recorded or saved, and no speech recognition is used.
  • Calm-down helper: if a parent turns this on, Pip can listen on the device during Break Time and may pause a video when it notices a sound. Listening itself is not stored, except the short practice recordings a parent chooses to teach or to ignore (described above).

Speech

Sentences are spoken by the device’s built-in text-to-speech engine. Pip does not send those sentences to a network service for speaking.

Break Time and YouTube (a third party)

The internet is used only when a parent starts Break Time with a video. Talking, photos, settings, taught-sound recordings, and ignore recordings do not use the internet. If a parent never starts Break Time, Pip does not contact YouTube or Google.

Opening Break Time from the talk board first requires the same Grown-ups only parent security questions used for Parent settings. A child cannot start a video by tapping the Break Time button alone. The Play version of Pip then plays only the YouTube videos that parent has chosen, in YouTube’s privacy-enhanced embedded player (youtube-nocookie.com). It does not include full YouTube search or browsing.

To play a chosen video, Pip sends YouTube the video identifier. YouTube (Google) may also receive ordinary technical playback information, such as device or player identifiers. That information is sent to Google, not to a Pip server. We do not get it back.

Google’s privacy policy, which covers YouTube, explains what Google collects and how it uses that information: https://policies.google.com/privacy. Suggested videos at the end of a video cannot be fully turned off by YouTube. The list of videos a parent picked stays on the device.

Children

Pip is made for children and is meant to be set up by a parent or caregiver. We do not collect personal information from children onto our own servers. Photos and optional taught-sound and ignore recordings stay on the device unless a parent chooses to include them in a Backup & Restore file they save themselves, as described above. The only time Pip itself sends information off the device is when a parent starts a Break Time video, as described above, in which case it goes to YouTube (Google) under Google’s privacy policy. Talking is free. Backup & Restore is unlocked for everyone during this launch. If purchases are ever added, they will be behind the parent gate.

How to delete information

In Parent settings you can remove personal words, taught-sound recordings, ignored sounds, and similar items. You can also clear the app’s storage in Android settings, or uninstall Pip. That deletes the information stored by the app on that device. It does not delete a Backup & Restore file a parent already saved somewhere else — the parent can delete those copies themselves. It also does not delete anything YouTube may have collected when a video was played. That is covered by Google’s privacy policy.
